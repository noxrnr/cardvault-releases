# cardvault releases

cardvault is a desktop app for tracking a Yu-Gi-Oh! card collection: search, binders, set
completion, card images in every language, CSV import and export, and backups. Support for other
trading card games may be added in the future.

This project holds only cardvault's releases: no code. Each release is under **Releases**, and
the app looks here for its updates.

cardvault is not affiliated with or endorsed by Konami. Yu-Gi-Oh! is a trademark of its owner.

## Installing
On Linux, download the release's `.AppImage` file, make it executable, and open it. A Windows
installer follows in a later release. cardvault keeps every
collection on the computer it runs on and sends none of it anywhere.

## Checking a release
How to check that a release's files are the ones published is in [SECURITY.md](SECURITY.md).

## Reporting a problem
Security problems: **Security**, then **Report a vulnerability** (private). Anything else: an
issue. Please put no personal data in an issue; it is public.
