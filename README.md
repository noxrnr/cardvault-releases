# cardvault releases

cardvault is a desktop app for keeping track of a card collection. This project holds
only its releases: no code. Each release is under **Releases**, and the app looks here for its
updates.

## Installing
Download the release's `.AppImage` file, make it executable, and open it. cardvault keeps every
collection on the computer it runs on and sends none of it anywhere.

## Checking a release
How to check that a release's files are the ones published is in [SECURITY.md](SECURITY.md).

## Reporting a problem
Security problems: **Security**, then **Report a vulnerability** (private). Anything else: an
issue. Please put no personal data in an issue; it is public.
